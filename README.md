# Just the Spin

A spinning wheel that fairly picks one item from your list. Part of the
[Keep It Neat](https://keepitneat.app) series — no ads, no tracking, no accounts,
works offline.

- Keep multiple named wheels, persisted on your device.
- Add items inline or paste a list (newline- or comma-separated).
- Optional: weighted slices, remove-the-winner draws, and a history of picks.
- Festive / monochrome / black-and-white palettes; system / light / dark themes.

## Develop

No build step, no dependencies.

```bash
python3 -m http.server 8764   # → http://localhost:8764
node --test                   # run all unit tests
```
